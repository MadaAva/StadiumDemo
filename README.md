# Stadium Demo

Live demo for building a Copilot Studio agent for a Nordic sports retailer.

**All data in this repository is synthetic.** Never use or request real customer,
member, or employee data.

## Repository layout

- `data/`: Synthetic demo datasets.
- `scripts/`: Short, readable Python standard-library scripts.
- `agent/`: Copilot Studio agent configuration and supporting materials.
- `tests/`: Tests for demo scripts and agent behavior.

## Demo guidelines

- Never put secrets, keys, or connection strings in code or commits.
- Use only the Python standard library unless explicitly approved otherwise.
- Keep code short and readable for presentation on a big screen.
- Keep local environment files out of version control.

Repository-wide Copilot guidance lives in
[.github/copilot-instructions.md](.github/copilot-instructions.md).
